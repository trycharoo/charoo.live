## Status definitions

- **PASS:** acceptance criteria verified at a stated level with recorded evidence; no whole requirement receives this status from source presence alone.
- **PARTIAL:** implementation or intended coverage has a documented missing path.
- **FAIL:** a documented violation remains open; this does not imply every path fails. Findings below retain the prior review's evidence level.
- **UNKNOWN:** implementation/test definitions exist, but current acceptance evidence is insufficient.
- **N/A:** explicitly outside the present assessment; no requirement is dismissed solely because this is a setup task.

Product flags such as CURRENT, CONDITIONAL and TARGET remain in the SRS. They describe implementation presence or policy separately from the verification statuses here.
